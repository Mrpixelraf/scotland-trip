# 西线独立候选：Glencoe山谷＋Kintyre高尔夫

查询日2026-09-14，行程日期2026年，时区Europe/London。[本人要求](https://github.com/Mrpixelraf/scotland-trip/issues/2#issuecomment-5671333616)：认可已有框架，另做西线并选择球会；随后补充希望观光进入山地。本页为独立比较方案，没有替代北线或代表全团同意。6位旅行者，各轮参加人数待登记；无预订。

## 先看地形，再选球场

西部Glencoe的深谷、峭壁和山峰适合本团想看的山地风光，A82穿过山谷，不必登顶也能看到山。东部Cairngorms同样是高山地区，并非全是低地；但原计划的Inverness–Brora以海岸为主，Boat附近以森林、河谷和远山为主。Kintyre的长处是海滩、海湾和丘陵，不能代替Glencoe。

依据：[NTS Glencoe地貌](https://www.nts.org.uk/visit/places/glencoe/highlights/the-glen)、[Cairngorms国家公园山地](https://cairngorms.co.uk/the-national-park/landscapes/mountains-and-the-plateaux)。

推荐路线：**Glasgow Central会合→Balloch / Loch Lomond→Crianlarich→Rannoch Moor / Glencoe→Oban→Tarbert→Machrihanish / Southend→Inveraray→Loch Lomond / Glasgow**。爱丁堡非必经，见[最新交通修正](transport-meeting-points.md)。在既有共同假期里，不再加入Brora或Boat；这是采用本西线时的取舍，并非已取消北线。

30日如果会合晚或疲劳明显，改住Balloch / Crianlarich一带，1日继续进Glencoe并取消可选九洞，短步行后南下；不要为了不确定球位赶夜路。若连这一节奏也赶，就把Glencoe / Oban多留一晚、Machrihanish改到3日只打一场；两轮与观光不能在迟到后原样全保留。

## 徒步如何与打球共存

- **Glencoe**：[Greenway](https://www.nts.org.uk/visit/places/glencoe/highlights/outdoor-adventures)5km、约2小时、爬升72m；更短的An Torr/游客中心林道可约30–60分钟。适合山谷观景，无须登顶。Woodlands与游客中心不是同一出发点，需要接送，约中午会合；不能默认徒步者独占一辆车。
- **Machrihanish**：[West Port Beach](https://www.walkhighlands.co.uk/argyll/west-port-beach.shtml)4.5km、1–2小时可缩短。北端停车场在Campbeltown以北，需要先送后接；不想接送可从村边海岸活动，具体路线不同。
- **Southend**：以Dunaverty Bay与Keil一带短程往返为主，约1–2小时游览后午餐等球手。不要把完整[Southend→Machrihanish Kintyre Way长段](https://www.walkhighlands.co.uk/argyll/southend-machrihanish.shtml)当成同一条短线。
- [Mull of Kintyre灯塔](https://www.walkhighlands.co.uk/argyll/mull-of-kintyre.shtml)4km、1.5–2小时、爬升305m，还需单轨道路接近；不是随手一小时景点。Davaar潮汐未核，不写进固定日程；Beinn Ghuilean平日林业限制沿用[既有核查](golf-walking-routes.md)。

只想打一轮的朋友自行选择：重视世界名场可选Machrihanish；想打更短、花费更低的一场可选Dunaverty，但短球场也有起伏和风，并不自动适合所有水平。球费按各轮实际参与人数计，大家仍可共享住宿与晚餐。

## 预算与其他候选的取舍

两场主球费：£120＋£65＝**£185/人**；加Woodlands九洞为**£209.95/人**。这是2×18洞＋1×9洞，不是三轮18洞。全部6人都打两场才为£1,110；按实际人数公式为120×Mach人数＋65×Dunaverty人数＋24.95×Woodlands人数。

住宿先按每间双床每晚£175–250作筛选占位，4晚、两人一间为£350–500/人；加两轮球为£535–685/人，加九洞为£559.95–709.95/人。**是预算假设，不是已查到的全团报价**；不含交通、普通餐饮、教学、球具租用、9月29日本人房晚和4日后的延长。原北线Kingsmills等酒店报价不能直接移用于西线。
